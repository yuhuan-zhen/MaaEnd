# Linux 侧文档集

MaaFramework 的 Linux 控制器（`MaaLinuxControlUnit`）与云终末地网页端在 Linux 上的控制链路文档。

## 为什么单独成集

MaaFramework 的 `2.4-控制方式说明` 回答了「**有哪些**截图/输入方式」，但没有回答：

- 每种方式**支持哪些能力**（相对移动？多点触控？）
- 不支持时**表现是什么**（报错？还是静默无效果？）
- `start_app` / `resolution` 这类 API 是否实现

结果是使用者只能读源码 + 实测。本集补的是这部分。
